# PRODIGY_CS_01# Caesar Cipher Encryption & Decryption 🔐

This project is a Python implementation of the **Caesar Cipher Algorithm**, developed as **Task-01** for my Cyber Security Internship.

## 📌 Features

- Encrypt text using Caesar Cipher
- Decrypt encrypted text
- User-defined shift value
- Preserves uppercase and lowercase letters
- Keeps spaces, numbers, and special characters unchanged
- Simple command-line interface

## 🛠️ Technologies Used

- Python 3

## 💻 Example

### Input

```
Message : Hello World
Shift   : 3
```

### Output

```
Encrypted Message : Khoor Zruog
```

### Decryption

```
Encrypted Message : Khoor Zruog
Shift             : 3

Decrypted Message : Hello World
```

## 📖 Algorithm

1. Take user input.
2. Ask for shift value.
3. Shift each alphabet by the given value.
4. Preserve non-alphabetic characters.
5. Display encrypted/decrypted text.
